# Түн кімге тиесілі: ұйқыға ма, экранға ма?

«Ұйқы ұзақтығының, экран уақытының және оқу үлгерімінің өзара байланысы» ғылыми жобасының интерактивті сайты.

## Сайтта не бар

- 6 эпизодтық 3D видео-түсіндірме (Three.js)
- 96 оқушының деректері: графиктер мен корреляциялар
- Жаңа нәтиже: медиация талдауы (экран әсерінің ≈ 29%-ы ұйқы арқылы өтеді)
- «Цифрлық күн батуы» тәжірибесінің жобасы
- Зертхана: ұйқы қарызының калькуляторы және зейін тесті
- Ғылыми сараптама және дереккөздер

## Құрылымы

Сайт бір файлдан тұрады: `index.html`. Сыртқы кітапханалар CDN арқылы жүктеледі (Three.js r128, Google Fonts), сондықтан құрастыру (build) қажет емес.

## Vercel арқылы жариялау

1. Осы репозиторийді GitHub-та ашыңыз.
2. vercel.com → Add New → Project → репозиторийді таңдаңыз.
3. Framework Preset: **Other**. Build Command бос қалады. Deploy басыңыз.

Сайт `https://<репозиторий-аты>.vercel.app` сілтемесімен ашылады.
